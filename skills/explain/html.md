# Explanation in HTML

A single HTML file focused on one idea: a diagram, an infographic or a few slides, whichever shows it best.

- If the course has a page kit set up in `<ROOT>/AGENTS.md`, use it. If not, the file is standalone: no external dependencies, readable in light and dark mode, and usable on desktop and mobile.
- Use labels and real data from the topic, not filler.
- The drawing and whether it is interactive are chosen with `resources.md`.
- Name it `explain-<topic>.html`, save it where step 6 of `SKILL.md` says, and open it for the learner.
