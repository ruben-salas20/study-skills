# Research sources

Instructions for the subagent that researches a topic or a phase. Whoever launches it gives you: the topic, the limits in `MISSION.md`, and the course's `Resources/` folder.

## Steps

1. **Look at what's already there.** Read the titles in `Resources/`. A source that is already there gets reused. Done when you know what the folder already covers.

2. **Map the topic.** Write the subtopics the mission asks for and the prerequisites they assume. Done when each subtopic fits in one line and together they cover the mission.

3. **Find sources for each subtopic.** Prioritize **primary** sources: official documentation, textbooks, open university courses, and peer-reviewed articles. If the topic changes fast, also prioritize recent sources and note the date of each one. A blog or video is included only if it explains something better than the primary sources, and it is marked as such. Done when each subtopic has at least one reliable source or is noted as a **gap**.

4. **Save each source** in `Resources/YYYY-MM-DD — <Site or author> — <Title>.md`, with today's date. Each file has: the link, which subtopics it covers, a 3-to-5-line summary in your own words, and its reliability (primary, secondary or popular). Summarize and link; the original text stays where it is. Done when each source from step 3 (**Find sources for each subtopic**) has its file.

5. **Return the report** to whoever launched you:
   - the map from step 2 (**Map the topic**);
   - one line per new source;
   - the gaps;
   - the **contradictions** between sources, with what each one says.
